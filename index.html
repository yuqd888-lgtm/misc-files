About me / 关于我

我把审美判断、网页技术和内容表达结合起来，让个人品牌从想法变成可展示、可传播、可接单的数字资产。

I build visually distinctive websites and creative pages for personal brands, creators, and small teams. My work connects positioning, visual direction, interaction details, and practical delivery so each page feels polished at first glance and useful after the first click.

我专注于个人品牌网站、创意落地页和内容视觉系统。相比只做一个“好看的页面”，我更在意它是否能说清楚你是谁、你能提供什么、别人为什么愿意继续了解你，并把这种专业感落到结构、视觉和交互里。

06 / Process

Process / 工作方式

01

需求沟通

先确认你是谁、想吸引谁、希望别人看完采取什么行动，再整理参考风格、页面内容和合作目标。

输出：定位方向 / 内容清单 / 参考风格
02

风格提案

围绕首屏气质、字体、色彩、版式和交互感觉做方向确认，让审美先对味，再进入完整制作。

输出：视觉关键词 / 首屏方向 / 页面节奏
03

设计制作

把确认好的方向做成真实网页，完成内容模块、响应式适配、动效细节和必要的交互状态。

输出：完整页面 / 交互动效 / 手机适配
04

测试交付

检查电脑端与移动端体验，修正文字、间距和链接细节，交付可上线文件，并说明后续如何替换内容。

输出：上线文件 / 替换说明 / 修改建议
